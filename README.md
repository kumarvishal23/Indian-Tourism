# Indian Tourism – Travel & Explore India

A visually appealing **Indian Tourism landing page** designed to showcase the rich culture, heritage, destinations, experiences, and diversity of India. The project focuses on creating a modern and engaging frontend interface for a tourism/travel website.

## 🌐 Project Overview

**Indian Tourism** is a responsive-style frontend website that provides users with an attractive introduction to India's travel destinations and experiences.

The website includes sections for exploring destinations, customized travel packages, cultural and spiritual experiences, Indian cuisine, traveler testimonials, travel blogs, and booking/contact options.

The project was developed as a **frontend development project**, focusing on webpage structure, styling, visual presentation, and user experience.

## ✨ Features

* 🏠 Attractive hero/landing section
* 🇮🇳 Introduction to Indian tourism
* 🗺️ Top Indian destinations section
* 🎒 Unique travel experiences
* 🧳 Customized tour packages
* 🛕 Spiritual and pilgrimage tour section
* 🍛 Indian cuisine and culinary experiences
* ⭐ Traveler testimonials
* 📝 Travel stories/blog section
* 📅 Booking and contact call-to-action section
* 📧 Newsletter subscription section
* 📱 Clean and organized navigation
* 🎨 Custom visual design with images and decorative elements

The main page contains navigation links such as **Explore India, Tours, Destination, and More Options**, along with an Explore/Learn More interface.

## 🛠️ Tech Stack

* **HTML5** – Website structure and content
* **CSS3** – Styling, layout, colors, typography, and visual design
* **Bootstrap 5.3.3** – Frontend styling/framework support
* **Font Awesome 6.6.0** – Icons
* **Google Fonts** – Montserrat, Cormorant Upright, and Inknut Antiqua
* **Git & GitHub** – Version control and project hosting

The project imports Bootstrap, Font Awesome, and multiple Google Fonts directly in the HTML file.

## 📄 Website Sections

### 1. Hero Section

Introduces the website with the heading **"Discover the Wonders of India"**, supporting text, navigation, and an image-based visual layout.

### 2. Gateway to India

Provides an introduction to India's heritage, culture, landscapes, temples, bazaars, and beaches.

### 3. Best of India

Highlights:

* Top Destinations
* Unique Experiences
* Customized Packages

### 4. Travel Services

Showcases different tourism experiences including:

* Spiritual/pilgrimage tours

### 5. Why Travel With Us?

Highlights personalized and hassle-free tours supported by experienced guides and travel experts.

### 6. Traveler Testimonials

Displays reviews from travelers to provide social proof and improve visitor engagement.

### 8. Booking & Contact

A dedicated call-to-action section encourages users to book tours or contact the tourism service.

## 🎨 Design

The website uses a warm travel-inspired visual theme with:

* Burgundy/maroon accent colors
* Cream and off-white backgrounds
* Rounded image cards
* Decorative background elements
* Serif typography for headings
* Modern sans-serif typography for body text
* Image-based destination and experience cards

The CSS defines the primary accent color as `rgba(154, 33, 67, 1)` and uses Montserrat and Cormorant Upright typography.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Indian-Tourism.git
```

### 2. Open the project

```bash
cd Indian-Tourism
```

### 3. Run the website

Simply open:

```text
index.html
```

in your web browser.

Alternatively, you can open the project using **Visual Studio Code** and use the **Live Server** extension for a better development experience.
